### Defeitos encontrados e corrigidos durante a ET02

| Defeito                                                                                                                 | Correção                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| CHECKs com resultado `NULL` seriam aceitos (conclusão sem providências, cancelamento sem motivo, evento sem `to_value`) | `IS NOT NULL` explícito e `COALESCE(..., false)` nas regras por tipo de evento, antes de aplicar a migration |
| O Prisma gera `BIGSERIAL` para `audit_logs.id`; o PDF pede identidade                                                   | conversão para `GENERATED ALWAYS AS IDENTITY` na migration 3, sem editar a migration 2 já aplicada           |
| `[auth.email] enable_signup = false` desligava o login por e-mail no Supabase local (`email_provider_disabled`)         | chave mantida `true`; cadastro público bloqueado por `[auth] enable_signup = false`                          |
| Placeholder de `SEED_DEMO_PASSWORD` no `.env.example` acusado pelo gitleaks (quebraria a CI)                            | valor vazio, com instrução                                                                                   |
| Seed: pesos zero no `weightedArrayElement` do faker                                                                     | pesos zero filtrados                                                                                         |
| Teste de privilégios avaliava funções sobre objetos de outros esquemas                                                  | consulta reescrita com `CASE` e OIDs                                                                         |
